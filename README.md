# Katsu Pocket

A Chrome extension (Manifest V3) that floats a tiny retro handheld over every page you visit.

## Load it

1. Open `chrome://extensions`
2. Turn on **Developer mode**
3. Click **Load unpacked** and pick this folder
4. Click the toolbar icon to switch the handheld on or off. Once on, it follows
   you to every page and tab until you switch it off (toolbar icon or **×**).
   Drag it anywhere by its shell, or resize it with the grip in its bottom-right
   corner; it remembers its position and size.
   (Chrome doesn't allow it on `chrome://` pages or the Web Store.)

## Controls

| Button   | Keyboard |
| -------- | -------- |
| D-pad    | Arrow keys |
| A / B    | X / Z |
| Start    | Enter |
| Select   | Shift |

You can also click the buttons on the shell itself. Click the handheld first so
it has keyboard focus.

## Shells & boot

When you switch it on it plays a boot animation on the screen with a chime,
then hands over to the game. Hover the bottom edge of the shell to reveal the
toolbar: pick one of seven colours from the swatches, and toggle
**Classic / Color** to switch the boot between four shades of green and full
colour, each with its own chime. Both choices are remembered. The **×** closes it.

The shells, the boot animation and the chimes are original work made for this
project. The boot animation is pixel art drawn in `src/boot.js`; the shells
(SVG) and chimes (WAV) are generated by a script with no dependencies:

```
node tools/build-assets.mjs
```

Edit the colours, shapes or notes in that script and run it again to rebuild
them. The name shown on the boot screen is `NAME` in `src/popup.js`.

## Web mode

Hover the bottom edge and click **Web** to browse the internet on the handheld's
screen (click **Game** to go back). Type a URL or a search into the bar at the
top of the screen. **B** or **‹** goes back; **Start** jumps to the URL bar.

Pages are laid out in a ~385px phone-sized viewport and scaled down to fit.
Most sites refuse to be embedded, so while web mode is open in a tab the
extension strips `X-Frame-Options` and `Content-Security-Policy` from frames
in that tab. That's why it asks for access to all sites. Some caveats:

- Sites see you as an embedded third party, so you'll usually be signed out.
- Sites that detect framing with JavaScript may still refuse to render.
- Changing page or tab reloads the embedded site (it reopens the same address).

## Layout

```
├── manifest.json
├── assets/
│   ├── icons/           # 16/48/128 toolbar icons
│   ├── shells/          # one SVG shell per colour, on a 1076×1845 grid
│   └── sounds/          # chime-classic.wav, chime-color.wav
├── src/
│   ├── background.js    # toolbar click injects overlay.js; web-mode framing rule
│   ├── overlay.js       # content script: floating, draggable, resizable frame
│   ├── frame-reporter.js # reports the web-mode page's address to the handheld
│   ├── offscreen.html/js # plays boot chimes (web pages would block autoplay)
│   ├── popup.html       # shell + screen + button hotspots (loaded in the frame)
│   ├── popup.css
│   ├── boot.js          # boot animation: pixel font, sprite and drawing
│   └── popup.js         # boot, shell picker, game screen, web mode + input
└── tools/
    └── build-assets.mjs # generates assets/shells and the chimes
```

`assets/skins/`, `assets/gameboy.gif`, `assets/gameboy-adv.gif`,
`assets/sounds/gameboy.mp3` and `assets/sounds/gameboy-color.mp3` are kept from
the first version. Nothing loads them any more.
